# E-HOVER-01 — integrated build design baseline

The canonical DingoOS repository now consolidates the E-HOVER-01 work into a build-oriented baseline for the first physical article: a modular, uncrewed, bench-only propulsion-and-control demonstrator.

- [Integrated build design baseline](https://github.com/phillipbarnard07-cell/DingoOS/blob/integration/all-github-repositories/docs/advanced-systems/E-HOVER-01-INTEGRATED-BUILD-DESIGN-V1.md)
- [Progress record](https://github.com/phillipbarnard07-cell/DingoOS/blob/integration/all-github-repositories/progress/2026-10-10-e-hover-integrated-build-design-v1.md)

The package defines subsystem boundaries, command/safety states, independent inhibit requirements, interface-control fields, work packages, acceptance criteria and a design-closure ledger. It explicitly identifies the missing inputs needed for a physical BOM, CAD, electrical single-line diagram and propulsion selection. No vehicle-specific values are fabricated.

Status: conceptual/bench-article design baseline; NOT BUILT; NOT AUTHORIZED for powered testing, tethered operation or flight. Component selection, geometry, electrical ratings, hardware-specific hazard analysis, runtime test evidence and human authorization remain outstanding. This is not a construction-ready aircraft package.

No paid CI or external service introduced.
